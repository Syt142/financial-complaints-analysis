# 数据卡与16字段字典（累积至阶段二）

研究题目：金融产品月度投诉量的异常增长识别研究——基于大规模投诉记录的时间回测。

老师提供的本地CFPB格式快照：8,925,381,287字节，16,545,376条，16列，2011-12-01至2026-07-05。字段定义参考CFPB官方数据库及How we share complaint data（访问2026-11-08）。CFPB官方公开数据可供使用、分析和构建应用；教师快照的原下载批次、额外转换及再分发条件未核实。原始文件不发布；以已有源SHA-256及阶段一清单固定本批数据，未重新下载或重扫。

观察单位从一条投诉转换为一个原始产品标签×UTC日历月。主实验仅使用月度计数，不使用回应、转交日期、文本、地区或公司作为特征。保留无文本记录，避免将23.06%的文本子样本当作全体。

| 原字段 | 类型/解释 | 本阶段用途及风险 |
|---|---|---|
| Date received | 日期时间；收件日期 | UTC月份；非法另计，不静默填补 |
| Product | 类别；消费者选择的产品 | 保留原标签，禁止跨历史改名自动合并 |
| Sub-product | 类别；子产品 | 不参与基线，缺失不填类别 |
| Issue | 类别；问题 | 不参与评分，原标签可能变化 |
| Sub-issue | 类别；子问题 | 不参与评分 |
| Consumer complaint narrative | 可空文本；历史公开叙述 | 不读取或发布叙述；可能含残余敏感信息 |
| Company public response | 可空类别；公司公开回应 | 事后信息，不作特征 |
| Company | 类别；公司名称标签 | 不比较公司质量，缺少客户量分母 |
| State | 地区类别 | 不作特征，避免细粒度画像 |
| ZIP code | 字符串；邮编或屏蔽值 | 不转整数，不导出个人级位置 |
| Tags | 可空标签 | 可能涉及年龄/军人身份，不作特征 |
| Submitted via | 渠道类别 | 不作特征，渠道变化仍可能影响覆盖 |
| Date sent to company | 可空日期时间 | 事后流程信息，不作特征 |
| Company response to consumer | 可空类别；回应结果 | 不等于满意度，不作预测目标 |
| Timely response? | Yes/No等 | 不等于解决问题，不作特征 |
| Complaint ID | 标识符字符串 | 阶段一精确数值ID诊断；不作特征 |

历史质量：ID缺失2,390、重复额外记录0；Product缺失121；叙述空值12,730,795；UTC日历日倒置7,054（精确时间戳7,055）。不删除或“修正”这些记录。月表总量与完整数据总量对账后，明确按六个原产品标签缩小研究范围。主实验排除2026全年以规避不完整年度和快照右端累积延迟；排除不连续征信标签；缺月停止而不是补零。

主面板为六类原标签2017-05—2025-12，共104月×6=624个产品月。暖启动72、开发336、验证144、保留测试72。测试只查结构和记录划分，不导出评分；阶段三再统一比较。原始快照是事后可见数据，收件月份不等于数据实际公开可用月份；本实验仅支持回顾性时间回测。无法保证现实在线独立性，不能声称提前预警效果。

官方边界：投诉不是消费者经历的随机样本；不含未投诉者、未提交到该渠道者及部分转交其他机构者。产品规模、媒体事件、政策、渠道和类别变化都可能影响数量。无真实异常标签，无市场暴露分母；评分不是概率或因果结论。

参考：https://www.consumerfinance.gov/data-research/consumer-complaints/ ；https://www.consumerfinance.gov/complaint/data-use/
