# 阶段二冻结的实验方案

目标是完整月结束后的回顾性候选排名，服务课程分析者的有限人工复核。六个原标签和时间边界见configs/phase2.json。其余标签不用于主实验；不能把六类结果推广到全部16,545,376条投诉。

输入为阶段一经过哈希核验的month_product计数。先核对全月表计数与full_run.json总量，再逐月检查所选产品。缺月报错，显式0保留。2017-05—2018-04暖启动，2018-05—2022-12开发，2023-01—2024-12验证，2025-01—2025-12保留测试。同月各产品始终同属一段。第一阶段看过2025年度汇总，因此保留集并非从未接触过的数据；不读取其评分进行设计。保留期只核验结构，后续不再依据测试排名调参。

历史窗口固定12月，不搜索最优窗口。基线为历史中位数m，MAD为历史绝对偏差的中位数；尺度s=max(1.4826*MAD,1)，得分=max(0,(当前计数-m)/s)。尺度下限单位为“条”，避免零波动分母。1.4826是常见正态一致性尺度约定，不表示计数服从正态；得分不是z检验或概率。输出尺度触底提示，后续必须分析该约定对低计数序列的影响。

主决策为验证期144个候选中正分数前20个；按分数降序、月份升序、产品字典序解决并列。预算是两年共20条，不是每月20条。第20名分数是该次名单的截断点，不是通用异常阈值；更换时间窗需重新说明预算。没有真实标签，不计算真实准确率、精确率或误报率。主模拟指标为单点注入进入Top20的比例；次要报告候选产品集中度、自然流正分数比例、评分范围与耗时。

模拟：固定10个种子0—9，每个种子从验证期144个位置中无放回抽20个，不同种子允许重复。每次复制原始计数，仅在一个位置加入ceil(n*f)条（至少1条），f=0.25/0.5/1/2。同一次位置跨幅度配对，4档共800次回测，每档200次。注入后重新评分整段，允许其影响后续12个月的历史基线，以保持滚动过程一致。预算始终20，原始文件不变。种子均值、标准差、最小最大值表示位置敏感性，不是总体置信区间；原始流中已有异常未知，因此不是干净负类实验。

验收：手算例100×12→130的基线100/MAD0/尺度1/分数30；未来值改动不影响过去；历史缺月报错；重复/负计数拒绝；输入不变且位置跨幅度配对；原20项测试及新增测试通过；全量计数与证据哈希通过；同一配置重建相同排名和模拟统计。检出率不设事后合格线，低检出和非单调结果均如实保留。

阶段三计划：在相同可用历史、切分、验证预算及模拟位置下比较本基线、可解释统计模型、Isolation Forest；仅在开发/验证期选择参数。补窗口/尺度下限敏感性分析、典型失败和人工复核；不能用假定异常当作真值。阶段四集成输入—检测—解释，阶段五再检验文本覆盖/分类提示扩展；文本按产品月交叉分析需要新增扫描，未在阶段二冒充完成。
